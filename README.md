# Casos Críticos — Demo

Demo visual de la aplicación de gestión de Casos Críticos (International).

> ⚠️ **Nota:** esta es una demostración visual con datos de ejemplo.
> No está conectada a SharePoint; sirve para mostrar el diseño y la interacción.

## Ver en vivo (GitHub Pages)

1. Sube estos archivos a un repositorio de GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, elige la rama `main` y la carpeta `/ (root)`.
4. Guarda. En 1-2 minutos tu demo estará en:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`

## Archivos
- `index.html` — la aplicación demo (logo incluido, autónomo)
